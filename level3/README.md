# Level 3: Production / End-to-End HPC Applications

Not implemented yet.

Level 3 covers production or end-to-end HPC applications. These may involve
multi-GPU, multi-node execution, job schedulers, and external libraries, so
the Level 1 layout is not enforced here.

Planned layout (reference only):

```
level3/<application_name>/
├── README.md
├── source or integration files
├── build files
├── configs/
├── jobs/
└── run.sh
```
