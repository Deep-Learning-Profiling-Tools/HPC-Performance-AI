How to read and regenerate this page

method

ROI: median of the clean runs (no profiler), timed by the markers themselves. Device busy: union of all device activity inside the ROI in the profiled run. Host gap: ROI minus device busy -- time in the ROI when the device was idle. Profiler ×: profiled ROI / clean ROI. Entries: how often the ROI was entered (their times add up). Method and placement rule: tools/timing/README.md, roi/README.md, formats SCHEMA.md.

Every measure_level1.sh / measure_level2.sh run summarizes its data and rewrites results/timing/report/. To update the copy in the repository: python3 tools/timing/report.py --publish (writes docs/timing/), then commit it.
